# Topic to Video

**把一个选题或观点，做成口播、配片、剪辑包装、封面和发布文案。**

一套面向 AI 科普、知识口播与短视频创作者的开源 Skill / 创作 SOP。

</div>

## 它解决什么问题？

选题想好了，却不知道怎么搭框架、怎么让开头留住观众；文案写好了，又缺配套 B-roll；不想真人出镜，还要摸索数字人；剪辑、字幕、包装、封面和发布文案分散在多个环节，每次都要从头组织。

Topic to Video 把这些环节串成一条可确认、可修改、可续作的流程。你输入选题、观点或初步大纲，AI 负责规划和推进，你在关键节点确认内容、审画面、选风格。不满意直接提出修改；已有素材和已确认决定会保留。

核心观点是：**视频创作要让内容、画面和剪辑一起推进。先审画面，再定稿口播。** 草稿先指导配片，实际画面通过后再修订文案，让口播真正对应观众看到的内容。已有最终实录时，则以实录和真实字幕时间为准安排画面。

## 创作 SOP

| 步骤 | AI 做什么 | 你确认什么 |
| --- | --- | --- |
| 1. 选题 → 观点 | 明确观众、痛点、结果承诺；搭建开头、案例、讲解与总结 | 这条视频要讲什么、给谁看 |
| 2. 草稿 + 配片计划 | 同时写口播草稿、镜头清单和 B-roll 提示词 | 框架与素材方向 |
| 3. 先审画面 | 生成或接收素材，检查实际表达，修订匹配的口播 | 画面是否合格、口播是否定稿 |
| 4. 出镜与字幕 | 走真人、数字人或纯配音路线；合并素材并转写对齐 | 人声、出镜与字幕 |
| 5. 风格预览 | 根据参考截图或候选方案，预览字幕、章节卡与解释图 | 视觉风格 |
| 6. 剪辑包装 | 规划出镜与配片切换，用真实时间轴完成字幕、动效和音频 | 分镜与审阅版 |
| 7. 发布物 | 输出最终视频、封面候选、标题、正文和标签 | 最终效果与封面文案 |
| 8. 复盘 | 保存状态和项目内偏好，下一次可明确选择复用 | 哪些经验值得保留 |

例如输入“为什么 AI 视频的画面很好看，却讲不清楚一个概念？”，工作流会先提炼观点，组织可见案例，再为各段规划配片。素材审阅后确定口播，录制完成后用实际音频对齐字幕和包装，最后交付封面与发布文案。

## 快速开始

本仓库采用标准 `SKILL.md` 目录结构。以 Codex 为例，克隆后把整个 Skill 文件夹复制到你的技能目录；已有同名 Skill 时先自行备份并合并。

```bash
git clone https://github.com/Newdvn2025/topic-to-video.git
mkdir -p ~/.codex/skills
cp -R topic-to-video/skills/topic-to-published-video ~/.codex/skills/
```

重新打开会话或刷新技能后，输入：

```text
使用 $topic-to-published-video，把这个选题做成完整视频：
为什么 AI 视频看起来很好看，却讲不清楚一个概念？
面向 AI 创作新手，目标 90 秒，16:9 横屏。
先给框架、口播草稿和配片提示词，画面审阅通过后再定稿口播。
```

也可以从中间开始：

```text
我已经有口播视频、SRT 和 B-roll。
使用 $topic-to-published-video，按真实字幕时间安排配片、章节卡和总结。
参考我上传的截图，先给风格预览，再用可用的 HyperFrames 或 Remotion 制作审阅版。
```

后续可以说“继续”“这段画面和口播不对应”“章节卡更简洁一点”，Skill 会读取项目状态并推进或修改。其他支持文件夹式 Skill 的 Agent 可按自身安装方式加载 `skills/topic-to-published-video/`。

## 工具接入与能力边界

**本仓库提供流程指令、参考文档和交付物约定。** 它不捆绑视频模型、API 调用脚本、数字人模型、ChatCut、HyperFrames 或 Remotion，也不提供这些服务的账户与额度。

| 环节 | 可选接入路线 |
| --- | --- |
| B-roll | 已配置的 MiniMax H3 调用工具、AutoDL 适配器或其他生成服务 |
| 数字人 / 配音 | 自己的数字人服务、可用配音工具，或直接导入成品素材 |
| 多段合并与字幕 | ChatCut 或已有剪辑、转写工具 |
| 动态包装 | HyperFrames 或 Remotion 及对应技能和运行环境 |
| 图解与封面 | 可用图像生成工具，或用户提供的图片 |

Agent 会先检查实际可用能力。未接入生成或渲染工具时，仍可产出内容框架、文案、提示词、素材计划和制作要求；完整成片需要相应工具可用。MiniMax H3 的调用工具需另行安装配置；服务费用依实际供应商、配置和计费规则而定，本仓库不承诺固定单价。

你可以使用真人口播、数字人或纯配音。逐词字幕取决于转写工具支持；普通 SRT 来自真实音频。参考截图可用于提炼版式、配色和动效方向。

“越用越贴合习惯”指把确认后的偏好与复盘记录保存为文件，后续明确复用；不是自动训练模型。更新持久偏好或 Skill 需要用户提出要求，个人项目记录不会自动写进公开仓库。

## 会交付什么？

- 内容定位、口播草稿与最终稿。
- 配片提示词、素材清单和已生成/导入素材。
- 真实音频对应的字幕；工具支持时附逐词时间。
- 视觉规范、时间轴分镜、可继续修改的工程源文件。
- 审阅版、最终视频与质量检查记录。
- 封面、发布标题、正文与相关标签。

各项以实际制作方案和工具能力为准，缺失项会明确记录。生成作品保存于你自己的项目目录。仓库只含通用 Skill 和文档，不含创作者原始视频、声音、数字人、客户资料、项目文件或凭据。
